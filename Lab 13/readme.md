# Assignment 13: Flexbox Layouts

## Aim
To create navigation bars, centred cards
and wrapping cards using CSS Flexbox.

## Task 1: nav-flex.html
- Created a horizontal navigation bar.
- Added four links: Home, About, Events and Contact.
- Used display: flex.
- Added dark background and white text.

## Task 2: centred-cards.html
- Created three cards in one row.
- Added Starter, Standard and Premium plans.
- Added prices 199, 349 and 499.
- Used justify-content: center.
- Used align-items: center.

## Task 3: wrapping-cards.html
- Created a Stationery Shop heading.
- Added four product cards.
- Notebook: 60
- Pen: 15
- Bag: 350
- Book: 120
- Used display: flex.
- Used flex-wrap: wrap.

## How to Run
1. Open Lab 13 in VS Code.
2. Open each HTML file.
3. Run using Live Server.
4. Take screenshots of all three pages.
5. Resize the browser to check card wrapping.
