Lab 15: Responsive Pages with Media Queries

Aim:
To use CSS media queries to create responsive layouts, make images scale with their containers, and set text sizes using rem units.

Tasks Completed:

1. Mobile First Layout

- Created "mobile-first.html".
- Added two cards with headings and paragraphs.
- Used Flexbox to stack cards on mobile screens.
- Used a media query at 600px to display cards side by side.

2. Responsive Image

- Created "responsive-image.html".
- Added a heading and an image.
- Used "max-width: 100%" and "height: auto".
- Made the image responsive for different screen sizes.

3. Responsive Text

- Created "responsive-text.html".
- Added an h1 heading and a paragraph.
- Set body font size to 1rem.
- Set heading size to 1.5rem.
- Used a media query at 600px to change heading size to 2.5rem.

Technologies Used:

- HTML5
- CSS3
- CSS Media Queries
- Flexbox

Conclusion:
Successfully completed Lab 15 by creating responsive web pages using CSS media queries.
