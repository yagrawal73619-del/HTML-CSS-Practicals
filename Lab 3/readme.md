Assignment 3: Your First HTML Page

Aim:-
To create a first HTML page with a title, headings, and a paragraph, and format text using HTML tags.

Tasks

1. Create first.html

- Created an HTML document with proper document structure.
- Added the title My First Page.
- Added an H1 heading: Hello, I am Asha.
- Opened the HTML file in a web browser.

2. Create headings.html

- Created an HTML page using different heading tags.
- Added an H1 heading, H2 heading, and H3 heading.
- Added one paragraph with sample text.
- Demonstrated different heading sizes.

3. Create text-format.html

- Created an HTML page with two paragraphs.
- Used the "<strong>" tag to make a word bold.
- Used the "<em>" tag to make a word italic.
- Added a line break using the "<br>" tag inside a paragraph.

Files Created

1. "first.html"
2. "headings.html"
3. "text-format.html"

Output

- First page displays the title and a large heading.
- Headings page displays H1, H2, H3 headings and a paragraph.
- Text formatting page displays bold, italic text and a line break.

Conclusion:-
Successfully completed Assignment 3 by creating basic HTML pages and learning document structure, heading tags, paragraph tags, and text formatting tags.
