Assignment 6 – Types of HTML Lists

Aim:-
To create different types of HTML lists, including unordered lists, ordered lists with nested lists, and description lists.

Assignment Details

1. Shopping List

File Name: "shopping-list.html"

- Created a heading named Shopping List.
- Used the "<ul>" tag to create an unordered list.
- Added three items:
  - Notebook
  - Pen
  - Bag

2. Canteen Menu

File Name: "canteen-menu.html"

- Created a heading named Canteen Menu.
- Used the "<ol>" tag to create an ordered list.
- Added two items: Samosa and Sandwich.
- Created a nested ordered list under Sandwich containing:
  - Cheese
  - Vegetable

3. Library FAQ

File Name: "faq.html"

- Created a heading named Library FAQ.
- Used the "<dl>" tag to create a description list.
- Used "<dt>" for questions and "<dd>" for answers.
- Added two questions:
  1. How many books can I borrow? – You can borrow 3 books at a time.
  2. Is the library open on Sunday? – No, the library is closed on Sunday.

Concepts Used

- HTML Document Structure
- Heading Tag ("<h1>")
- Unordered List ("<ul>")
- Ordered List ("<ol>")
- List Item ("<li>")
- Description List ("<dl>")
- Description Term ("<dt>")
- Description Details ("<dd>")
- Nested Lists
