# Assignment 12: Box Model, Cards and Scrolling

## Aim
To compare CSS box sizing, style a card and create a scrollable box.

## Task 1: box-model.html
- Created two div boxes.
- First box uses content-box.
- Second box uses border-box.
- Both have 200px width, 20px padding and 5px border.

## Task 2: card.html
- Created a card using div.
- Added background colour.
- Added 2px border.
- Added 12px border-radius.
- Added 16px padding.
- Added h3 heading and paragraph.

## Task 3: scroll.html
- Created a box with 120px height.
- Used overflow: auto.
- Added five paragraphs inside the box.

## How to Run
1. Open the folder in VS Code.
2. Open each HTML file.
3. Run using Live Server.
4. Take screenshots of all three pages.
