# Assignment 8: Sign-Up Forms and Choices

## Aim
To create HTML forms using text, email, password fields, radio buttons, dropdown choices, and required attributes.

## Technologies Used
- HTML5
- Visual Studio Code
- Live Server

## Assignment Tasks

### Task 1: Signup Form
File: `signup.html`

- Full Name input field
- Email input field
- Password input field
- POST form method
- Submit button

### Task 2: Choices Form
File: `choices.html`

- Gender selection using radio buttons
- Male and Female options
- Course selection using dropdown
- BCA and B.Tech options

### Task 3: Required Signup Form
File: `signup-required.html`

- Full Name field
- Email field
- Required validation
- Name placeholder
- Submit button

## How to Run
1. Open the Assignment 8 folder in VS Code.
2. Open any HTML file.
3. Right-click and select Open with Live Server.
4. View the form in your browser.
