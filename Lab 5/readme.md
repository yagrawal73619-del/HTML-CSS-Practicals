Assignment 5: Links and Images

Aim:-
To link two HTML pages together and add an image with appropriate alternative text (alt text).

Tasks Completed

1. home.html

- Created a Home Page with the heading "Welcome to My Site".
- Added a paragraph containing a hyperlink to "portfolio.html".
- Clicking on the portfolio link opens the Portfolio page.

2. portfolio.html

- Created a Portfolio page with the heading "My Portfolio".
- Added a paragraph welcoming visitors to the portfolio page.
- Added a link to navigate back to "home.html".

3. portfolio-image.html

- Created a Portfolio Image page with the heading "My Portfolio Image".
- Added an image from the "images" folder.
- Set image width and height to 200 pixels.
- Added alternative text using the "alt" attribute.

Files Used

- "home.html"
- "portfolio.html"
- "portfolio-image.html"
- "images/photo.jpg"

Concepts Learned

- HTML Anchor Tag ("<a>")
- Hyperlinks using the "href" attribute
- Linking multiple HTML pages
- HTML Image Tag ("<img>")
- Image attributes: "src", "alt", "width", and "height"

Output

Successfully created two linked HTML pages and a portfolio image page using HTML.
