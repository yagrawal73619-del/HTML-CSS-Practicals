# Lab 9 – Tables with Headers and Footers

## Aim
To create HTML tables using captions, headers, body, footers and scope attributes.

## Technologies Used
- HTML5
- Visual Studio Code
- Live Server

## Task 1: marks.html
Created a table with:
- Caption: Marks of Class A
- Header: Name, Maths, Science
- Three student records: Asha, Rohan and Neha.

## Task 2: marks-average.html
Created a table with Asha and Rohan's marks and calculated class averages.
- Maths Average: 71
- Science Average: 77.5

## Task 3: marks-accessible.html
Created an accessible table using:
- scope="col" for column headings.
- scope="row" for student names.
